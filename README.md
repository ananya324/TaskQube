# Collaborative Workspace Platform

A realtime collaborative workspace platform built using the MERN stack and Socket.IO.

## Features

- Authentication
- Workspace management
- Task management
- Collaborative notes
- Realtime updates
- Presence system
- Reminders
- Activity tracking
- AI task summaries

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Socket.IO
- JWT Authentication

## Run Locally

```bash
npm install
npm run dev
